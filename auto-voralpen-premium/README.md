# Auto Voralpen Premium

Static landing page project for Auto Voralpen GmbH.

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

Example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Notes

The page currently uses external CDN assets for Tailwind CSS, GSAP, Iconify, Google Fonts, and the logo. The intro video is stored locally at `assets/intro-video.mp4`.
